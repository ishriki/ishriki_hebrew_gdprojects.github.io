# האתר של שרוליק שריקי

אתר עסקי ותיק עבודות בעברית לעיצוב גרפי ותקשורת חזותית.

## העלאה ל־GitHub Pages

1. חלץ את קובץ ה־ZIP במחשב. אין להעלות את קובץ ה־ZIP עצמו לאתר.
2. צור מאגר GitHub חדש, או פתח את המאגר שבו תרצה לפרסם את האתר.
3. העלה את **תוכן התיקייה שחילצת** לשורש המאגר. `index.html` ותיקיית `assets` צריכים להיות באותו מקום. שמור על מבנה התיקיות ועל שמות הקבצים.
4. במאגר, פתח **Settings → Pages**.
5. תחת **Build and deployment**, בחר **Deploy from a branch**.
6. בחר את הענף שבו העלית את הקבצים, בדרך כלל `main`, ואת התיקייה **/(root)**, ולחץ **Save**.
7. לאחר סיום הפרסום, כתובת האתר תופיע בעמוד Pages.

אם משתמשים באתר קיים, יש לגבות את הקבצים הקודמים לפני החלפתם. האתר מתאים גם למאגר פרויקט: הנתיבים לתמונות ולקטלוגים יחסיים ואינם תלויים בשם המאגר.

## פתיחה במחשב

פתח את `index.html` בדפדפן. אין צורך בהתקנה, בבנייה או בשרת כדי לעיין באתר. אם הדפדפן מגביל הורדה מקומית, ניתן לפתוח ישירות את קובצי ה־PDF שבתיקייה `assets/pdf`.

## מה כלול

- עמוד בית עם שם העסק, מבחר עבודות, סינון לפי תחום, אודות ויצירת קשר.
- ששת קטלוגי Cohen’s Line המקוריים ב־PDF, ללא שינוי בתוכן הקבצים, עם תצוגת כל 55 העמודים באתר.
- פרויקט הגריל של חיים: שלושה לוגואים, מיתוג חולצה ושני תפריטים, חזית וגב.
- פרויקט I.S.H: כרטיס ביקור, קובצי PDF המקוריים ושיפור העיצוב בעקבות משוב.
- כרזות, עבודות עימוד ואיור, כולל ארבעה קובצי PDF מהפרויקטים המקוריים.
- גלריית לוגואים וגלריית צילום.
- התאמה לטלפון, ניווט מימין לשמאל, הגדלת תמונות, ניווט מקלדת וקישורי הורדה.
- תמונות וגופני Heebo שנכללים בקבצים ומוגשים מתוך האתר עצמו.

## עדכון התוכן

- **פרטי העסק:** שם המעצב והטקסט מופיעים בקובצי ה־HTML.
- **מייל:** קישורי יצירת הקשר משתמשים בכתובת `ishriki@emich.edu`, כפי שהיא מופיעה בתיק העבודות המקורי. להחלפתה, חפש את הכתובת בכל קובצי ה־HTML והחלף אותה.
- **LinkedIn:** קישור הפרופיל נמצא בתחתית כל עמוד.
- **צבעים:** המשתנים בתחילת `assets/css/site.css` מגדירים את צבעי האתר.
- **תמונות:** נמצאות ב־`assets/images` וב־`assets/catalogs`.
- **מסמכים:** נמצאים ב־`assets/pdf`.
- **דפדוף בקטלוגים:** נתוני הקטלוגים נמצאים ב־`assets/js/data.js`.
- **התנהגות:** התפריט, סינון העבודות, הגדלת התמונות והדפדוף נמצאים ב־`assets/js/site.js`.

יצירת הקשר באתר מתבצעת באמצעות פתיחת תוכנת המייל של המבקר. אין טופס עם שרת לשליחת הודעות.

פרטי קשר ומידע מסחרי בתוך עבודות הלקוחות מוצגים כחלק מהפרויקטים המקוריים. הם אינם פרטי העסק של המעצב.
